# Tomax Pack Toggle (Fabric, Minecraft 1.21.11)

Right Shift in-game -> menu om de lTomaxMC packs aan/uit te zetten. Hitbox krijgt de kleur van de actieve pack.

## Op GitHub zetten
1. Upload ALLE bestanden uit deze map (sleep de inhoud in "Add file -> Upload files") en commit.
2. Klik op `build.yml` -> potlood (Edit) -> verander de bestandsnaam bovenin naar:
   .github/workflows/build.yml
   -> Commit changes.
3. Tab "Actions" -> wacht tot de build groen is -> download artifact `tomax-pack-toggle`.
4. Jar in .minecraft/mods/ (samen met Fabric API 1.21.11).
